📚 Concepto: Árbol Binario de Comentarios
▼ ver código

Cada comentario es un nodo del árbol. El hijo izquierdo = primera respuesta. El hermano derecho = siguiente comentario al mismo nivel. 

// Nodo del Árbol Binario
class CommentNode {
  constructor(data) {
    this.id          = data.id;
    this.content     = data.content;
    this.depth       = data.depth;
    // Punteros del árbol binario:
    this.leftChild   = null; // primera respuesta
    this.rightSibling = null; // hermano del mismo nivel
  }
}

// Recorrido recursivo para renderizar
_renderNode(node) {
  if (!node) return;
  render(node);                       // visitar nodo
  this._renderNode(node.leftChild);  // recorrer hijo
  this._renderNode(node.rightSibling);// recorrer hermano
}

🔷 El color del borde izquierdo de cada comentario indica su profundidad en el árbol (depth 0–10).
